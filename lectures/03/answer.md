# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素の LLM は講座の知識を持たないので、一般論で穴を埋めて断定に近い形で答える。エージェントは用語集という根拠を検索してから答えるので、正しく短く答えられる。そのぶん、1 つの質問で LLM を 2 回呼び、入力トークンも増える
- `--trace` で見えたツール呼び出し（ツール名と引数）：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` の 2 回（`tool_calls=2`）。docstring の「query には調べたい用語を1つだけ入れる」に従い、用語を 1 つずつ検索した。どちらも第2回の用語として定義が返った
- 1つの質問での LLM 呼び出し回数（`requests`）：2 回。ツール呼び出しは 2 回あったが、1 回目の応答で 2 つの検索をまとめて依頼したので、ツールの結果を受け取って答える 2 回目と合わせて 2 回で済んだ
- 追加したツールと、docstring に書いた説明：`make_quiz(lecture: int) -> str`。用語集から指定した回の用語を 1 つ選び、`{"question": "「…」の意味は？", "answer": <定義>}` を JSON 文字列で返す（その回の用語が無いときは、用語がある回の一覧を返す）。docstring には「指定した回の用語から 1つを選び、確認問題と答えを返す。」「「第2回の確認問題を出して」のように、復習用の問題を求められたときに使う。」と、何を返すかと使う場面を書いた
